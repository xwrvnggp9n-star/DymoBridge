DymoBridge is installed and running

To verify, open Chrome and go to:

https://127.0.0.1:41951/

You should see the DymoBridge health page listing the LabelWriter. Then log into Kipu and print a label as usual.

To remove DymoBridge later and restore the DYMO web service, an administrator can run /usr/local/share/dymo-bridge/uninstall.sh.
